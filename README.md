# DeepSeek-chan Assistant

DeepSeek-chan Live2D 모델로 만든 macOS/Windows 데스크톱 어시스턴트입니다. 화면 위에 떠 있는 캐릭터가 OpenAI 호환 API(DeepSeek 기본)로 대화하고, 표정과 동작을 바꾸며, 로컬 음성 합성으로 말합니다.

## 준비물

| | macOS | Windows |
|---|---|---|
| 지원 | Apple Silicon (M1 이상) | Windows 10/11 64비트 |
| 디스크 | 약 8GB | 약 10GB |
| 그래픽 | | 필요 없습니다. 음성은 CPU로 합성합니다 |

미리 설치할 것은 없습니다. 설치 스크립트가 Node.js, Python, 음성 엔진을 모두 이 폴더의 `runtime/`에 넣습니다. 시스템 PATH, 레지스트리, Homebrew, 사용자 폴더를 건드리지 않으며, 지우려면 폴더를 삭제하면 됩니다.

## 설치

### 1. 내려받기

```bash
git clone https://github.com/EveFreeman/deepseek-chan.git
```

ZIP으로 받아도 됩니다. Windows는 `C:\deepseek-chan`처럼 짧고 영문인 경로에 두세요. 긴 경로나 한글 경로에서는 Python 패키지 설치가 실패할 수 있습니다.

### 2. 설치 스크립트 실행

- macOS: `setup-mac.command`를 더블클릭합니다. 처음에 "확인되지 않은 개발자" 경고가 뜨면 우클릭 > 열기로 실행하세요.
- Windows: `setup-windows.bat`을 더블클릭합니다.

약 5GB를 내려받으며 20~40분 걸립니다. 실패하면 다시 실행하세요. 받은 것은 다시 받지 않습니다. 기록은 `runtime/setup.log`에 남습니다.

### 3. 모델과 음성 넣기

재배포가 금지된 두 가지는 저장소에 없습니다. 원래 배포처에서 직접 받아 넣으세요.

| 넣을 곳 | 받을 것 | 배포처 |
|---|---|---|
| `live2d/` | DeepSeek-chan 무료 Live2D 모델 | [VGen (제작자 KAMIYA)](https://vgen.co/KAMIYA/product/deepseek-chan-deepseek-free-live2d-model-layered-psd-psd/1c55a71a-2747-4616-819d-2dc0a934089d) |
| `voice/` | つくよみちゃんコーパス Vol.1 声優統計コーパス（JVSコーパス準拠） | [つくよみちゃん 공식](https://tyc.rei-yumesaki.net/material/corpus/) |

압축을 풀어 폴더째 넣으면 됩니다. 앱이 `大肥鱼.model3.json`과 `VOICEACTRESS100_011.wav`를 이름으로 찾으므로 폴더 이름은 상관없습니다. 각 배포처의 이용 규약을 지켜 주세요.

### 4. 실행

- macOS: `DeepSeek-chan.app` (설치 스크립트가 만듭니다. Dock에 끌어다 두면 편합니다)
- Windows: 바탕화면의 `DeepSeek-chan` 바로가기

처음 실행하면 트레이 아이콘 > 설정 > API 연결에서 키를 입력하세요. 키는 PC별로 암호화되어 `data/`에 저장되고, 다른 PC로 옮겨지지 않습니다. 설정과 대화 기록도 모두 `data/`에 있습니다.

켜져 있을 때 다시 실행하면 숨긴 캐릭터가 나타납니다. 끄는 것은 트레이 메뉴의 종료입니다.

### 업데이트

git clone으로 받은 폴더는 앱 안에서 업데이트됩니다. 설정 > 업데이트에 현재 버전(패키지 버전과 커밋, 날짜)이 표시되고, "업데이트 확인"으로 새 버전을 찾고 "다운로드하고 다시 시작"으로 받습니다. 앱이 켜질 때와 6시간마다 저절로도 확인해서, 새 버전이 있으면 캐릭터가 알려 주고 트레이 메뉴가 "업데이트 (변경 N개)"로 바뀝니다. 트레이 메뉴를 누르면 이 화면이 열립니다.

- 설정, 키, 대화 기록(`data/`)은 그대로 남습니다.
- npm 패키지가 바뀌었으면 함께 설치합니다. 음성 엔진이나 Electron이 바뀌었으면 설치 스크립트를 한 번 다시 실행하라고 안내합니다.
- 그 기기에서 코드를 직접 고쳤으면 덮어쓰지 않고 멈춥니다.
- 저장소가 비공개면 그 기기의 git에 GitHub 로그인이 되어 있어야 합니다. 처음 clone할 때 로그인했다면 따로 할 일은 없습니다. ZIP으로 받은 폴더는 앱에서 업데이트할 수 없습니다.

### 선택: 내 그림 넣기

`custom/dashboard.png`를 두면 대시보드의 기본 그림(`assets/dashboard.png`) 대신 표시합니다. 정사각형이 잘 맞습니다. `custom/`은 git에 올라가지 않습니다.

## 폴더 구성

| 폴더 | 내용 | git |
|---|---|---|
| `src/` `assets/` `scripts/` `test/` | 앱 코드 | 포함 |
| `live2d/` `voice/` | 직접 넣는 모델과 음성 | 제외 |
| `runtime/` | 설치 스크립트가 만드는 Node.js, Python, GPT-SoVITS, Whisper | 제외 |
| `vendor/` | 설치 때 받는 Live2D Cubism Core와 패치한 렌더러 | 제외 |
| `data/` | 설정, 암호화된 API 키, 대화 기록 | 제외 |
| `custom/` | 내 그림 | 제외 |

## 음성

기본 엔진은 [GPT-SoVITS](https://github.com/RVC-Boss/GPT-SoVITS) v2ProPlus입니다. 참조 음성의 목소리로 한국어, 일본어, 영어를 합성하며, 앱이 로컬 서버를 켜고 끕니다. Mac은 GPU(mps)로, Windows는 NVIDIA 그래픽카드가 있어도 CPU로 합성합니다. 짧은 문장에서는 CUDA가 CPU보다 빠르지 않았고 VRAM을 순간적으로 대부분 차지했기 때문입니다. Mac도 설정 > 음성에서 CPU로 바꿀 수 있습니다. 서버는 약 4~5GB의 RAM을 씁니다.

- 설치 스크립트는 GPT-SoVITS를 정해진 커밋으로 받고, Python 패키지는 함께 검증한 버전(`scripts/python/constraints.txt`)으로 설치합니다. 컴파일러가 필요한 `jieba_fast`와 Windows의 `eunjeon`은 `scripts/python/shims/`의 대체 모듈을 씁니다.
- 참조 텍스트(설정 > 음성)는 참조 음성의 대사와 같아야 합니다. 언어는 텍스트에서 자동으로 판별합니다.
- 음성 엔진은 애니메풍(기본), 외부 음성 API(OpenAI 호환), 끄기 중에서 고릅니다. 음성을 낼 수 없으면 대체 음성 없이 말풍선에 이유를 표시합니다.
- 중국어 합성에 필요한 G2PW 모델은 받지 않습니다.

## 웹 검색

모델이 필요할 때 DeepSeek Search·Fetch API를 도구로 호출합니다. 설정 > 일반에서 끌 수 있고, DeepSeek 키가 저장된 연결이 있어야 합니다. 요금은 성공 1,000회당 $0.75이며 대시보드에 집계됩니다.

- Fetch API가 읽지 못한 페이지(차단, 시간 초과, 빈 본문)는 앱이 이 PC에서 직접 받아 본문을 뽑습니다. 요금은 없고, 사이트에는 이 PC의 IP가 보입니다. 내부망 주소는 DNS로 확인한 실제 IP까지 막고, 리다이렉트마다 다시 확인합니다.
- 한 번에 여러 검색어와 페이지(호출당 3개)를 동시에 처리합니다.
- 긴 페이지는 앞부분과 질문에 관련된 문단을 골라 8,000자 안으로 줍니다. 다른 부분이 필요하면 모델이 같은 페이지를 다른 주제로 다시 읽습니다.
- 검색 결과와 읽은 페이지는 20분 동안 메모리에 보관해서, 같은 것을 다시 물으면 요금 없이 바로 씁니다.
- 출처에는 실제로 읽은 페이지가 먼저 표시됩니다.

프롬프트 인젝션 방어는 `src/main/web-guard.js`에 있습니다. 필터가 뚫려도 피해가 없도록 다음을 함께 씁니다.

- 도구는 읽기 전용 2개뿐입니다. 파일, 명령, 메시지 전송 도구가 없습니다.
- 페이지 읽기는 검색 결과나 사용자 메시지에 있던 URL로 제한되어, 대화 내용을 URL에 실어 내보낼 수 없습니다.
- 웹 내용은 숨은 문자와 주석을 지우고 길이를 제한한 뒤, 매번 다른 경계 태그로 감쌉니다.
- 지시문처럼 보이는 문장은 제거하고 말풍선에 경고를 표시합니다.
- 답변당 검색 3회, 새 페이지 읽기 4회(보관된 페이지 포함 8회)로 제한합니다.
- 웹 내용은 대화 기록에 남기지 않습니다.
- 말풍선은 텍스트로만 표시해서 웹 내용이 링크나 HTML이 되지 않습니다.
- DeepSeek 키는 실제 DeepSeek 연결에서만 가져오고 DeepSeek 외의 곳으로 보내지 않습니다.

남는 위험: 필터를 피한 문장이 답변 내용에 영향을 줄 수는 있습니다. 검색 결과를 근거로 한 답변은 출처를 확인하세요.

## 명령어

입력창에서 `/`로 시작하면 API로 보내지 않고 명령어로 처리합니다. 목록은 방향키와 Tab으로 고르고, `/`로 시작하는 문장을 그대로 보내려면 `//`로 씁니다.

- 웹: `/웹검색` 모드 전환, `/검색 질문` 이번만, `/읽기 URL 질문`
- 첨부: `/첨부파일`, `/클립보드`, `/첨부해제`, `/화면공유 질문`. 입력창 왼쪽 `+`, 또는 캐릭터나 입력창에 파일을 끌어다 놓아 첨부합니다. 첨부는 한 번 보내면 자동으로 빠지고, 칩을 누르면 Hold 상태가 되어 ×를 누를 때까지 유지됩니다. 화면공유는 미리보기에서 직접 눌러야 전송됩니다.
- 대화: `/다시`, `/복사`, `/요약`, `/번역`, `/모델`, `/기록`, `/새대화`, `/사용량`. 대화 기록은 이 PC에만 저장되며 모델에 보내지 않습니다. `/새대화`는 새 세션을 시작합니다. 기록 창에서 세션을 골라 다시 이어 갈 수 있고, 세션 삭제와 전체 삭제는 저장된 기록과 모델의 대화 기억을 함께 지웁니다.
- 캐릭터: `/밥`, `/쓰다듬기`(더블클릭), `/상태`, `/표정`, `/동작`, `/SD`, `/음소거`, `/숨기기`, `/대시보드`, `/설정`, `/도움말`
- 기억과 알림: `/기억해`, `/기억목록`, `/잊어`, `/알림 30분 뒤 회의`, `/알림취소`. "30분 뒤에 회의 알려 줘"처럼 말해도 예약됩니다.
- 더 찾기: `/문서 질문`(설정한 폴더), `/문서갱신`, `/깊게 질문`(현재 모델의 추론을 켬. 강도는 설정 > 일반), `/브리핑`, `/음성`
- 예산: 설정에서 차단을 켜면 넘었을 때 요청을 막고, `/강행 질문`으로 이번만 보냅니다.

전역 단축키: 선택한 글 처리(`Cmd/Ctrl+Alt+X`), 음성 입력(`Cmd/Ctrl+Alt+V`). 선택한 글 읽기는 macOS의 손쉬운 사용 권한, 음성 입력은 마이크 권한이 필요합니다. 음성 인식은 `runtime/whisper`로 로컬에서 합니다.

알림, 기억은 사용자의 입력으로만 만들어지며 모델이나 웹 내용이 추가할 수 없습니다. 문서 검색은 지정 폴더만 읽고, 찾은 부분만 모델에 보냅니다.

이미지 입력은 비전을 지원하는 모델에서만 됩니다. DeepSeek는 `deepseek-flash`입니다.

## 조작

| 동작 | 방법 |
|---|---|
| 입력창 열기/닫기 | 캐릭터 클릭, 또는 전역 단축키 (기본 `Cmd/Ctrl+Shift+Space`) |
| 보내기 / 줄바꿈 | `Enter` / `Shift+Enter` |

단축키는 설정 > 일반에서 바꿉니다.

## 개발

```bash
export PATH="$PWD/runtime/node/bin:$PATH"   # Windows: runtime\node
npm start
npm test
```

- `src/main/` Electron 메인: 창, 트레이, 메뉴, 단축키, LLM(`llm.js`), 음성(`gptsovits.js`, `stt.js`), 요금(`pricing.js`), 설정(`store.js`), 대화 기록(`transcript.js`)
- `src/renderer/` `companion.*` 플로팅 캐릭터, `control.*` 설정 창, `character.js` Live2D 제어
- `src/shared/` 동작 프리셋(`motions.js`), 명령어, 태그 파서
- `scripts/patch-live2d.js` 모델의 곱하기/스크린 색을 지원하도록 `pixi-live2d-display` 렌더러를 패치해 `vendor/`에 씁니다. `npm install` 때 자동으로 실행됩니다.
- 앱 안 자동 시험: `DSC_USER_DATA`(임시 프로필), `DSC_TEST_HOOK`(메인 프로세스에서 실행할 스크립트)

SD 모드는 모델에 내장된 `Clothes2` 파라미터(체형 변환)를 사용합니다. 앱은 모델 원본 파일을 수정하지 않고 읽기만 합니다.
